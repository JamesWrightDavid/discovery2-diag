# Discovery 2 fault dictionary

The meaning of every known fault code per module — what it means, the likely cause, its severity and an inferred OBD-II P-code where one applies. This is the RAVE fault-finding section, rebuilt as a searchable store (`src/d2diag/dtc/`), served here and at the `/faults` endpoint.

> Generated by `tools/gen_fault_docs.py` from `src/d2diag/dtc/*.json`. The Td5 is not OBD2, so a P-code is an inferred cross-reference, not a code the ECU emits. Meanings are documented facts (see each row's source in the store); a code→meaning pairing is only `proven` once verified on the car; everything from a forum or vendor list is `candidate`.
