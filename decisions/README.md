# Decisions

This repo keeps only the ADRs that are specific to the Land Rover Discovery 2 pack
(ADR-0005, ADR-0007). Every platform-wide decision moved with the platform at the repo
split (ADR-0013): ADR-0001 to ADR-0004, ADR-0006, ADR-0008 to ADR-0014 and later ones are
in [openostler/ostler `decisions/`](https://github.com/openostler/ostler/tree/main/decisions).
